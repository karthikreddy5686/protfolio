# REACT J CONNECT (reactj) - High-Performance Digital Tech Agency Portfolio

A modern, high-performance agency web application built with **React**, **Vite**, and **Tailwind CSS**.

## ✨ Key Features
- **Hero Section**: Single-line value statement with brand-orange capability pills.
- **Tech Stack Ticker**: Dual-row infinite marquee showcasing core engineering tools.
- **About & Capabilities**: Realistic commercial photography cards for Web Development, App Development, and Digital Marketing.
- **Interactive Client Intake Form**: Directly reflects and syncs client submissions to Google Forms.
- **Our Clients Grid**: Dark glassmorphic showcase of enterprise brand partners.
- **Responsive & Minimalist**: Optimized for ultra-fast page load times and mobile responsiveness.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone git@github.com:karthikreddy5686/protfolio.git

# Navigate into project
cd protfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build
```bash
npm run build
```
